# Molar Mayhem

Free interactive study site for General Chemistry I, chapters 1–9 of OpenStax *Chemistry: Atoms First 2e*.

The site is static HTML, CSS, and JavaScript. It runs on GitHub Pages with no build step.

```bash
npm install
npm run dev            # http://127.0.0.1:5173/
npm test               # node --test on tests/*.test.js
npm run check:content
```
